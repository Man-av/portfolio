# Manav Sharma Portfolio

A static portfolio website for Manav Sharma, focused on data analytics and full-stack development.

## Structure

- `index.html` - Main portfolio page and GitHub Pages entry point
- `assets/` - Profile image, favicon, and resume
- `css/` - Portfolio styles and design tokens
- `pages/` - Standalone interactive visual demos
- `src/` - Reusable TypeScript/React components
- `archive/` - Local backup files, excluded from commits

## Run locally

Open `index.html` in a browser, or serve the repository with any static file server.

For GitHub Pages, publish the repository root with `index.html` as the entry file.
